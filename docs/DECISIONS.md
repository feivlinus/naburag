## 29-10-2026 — Container image & toolchain versions

**Images and Bun are pinned to exact versions (`oven/bun:1.4.4`, `qdrant/qdrant:v1.20.0`, `ollama/ollama:0.40.4`) in Compose and CI.** `latest` made local runs and CI non-reproducible and silently diverged from what the tests were run against.
