## Reporting a Vulnerability

We take the security of NabuRAG seriously. If you discover a security vulnerability or sensitive information leakage:

1. **Do NOT open a public GitHub issue.**
2. Please use GitHub's private vulnerability reporting feature:
   - Navigate to the repository's **Security** tab.
   - Click **Report a vulnerability** to submit a private advisory.
3. Include detailed steps to reproduce the issue and any relevant environment details.

Maintainers will review the report, develop a fix, and coordinate responsible disclosure.
